# Agendex System

| Component | Purpose |
| --- | --- |
| [Web application](web/README.md) | Browse repositories, define classification policies, and manage jobs and results. |
| [Data pipeline](pipeline/README.md) | Discover candidates, collect README evidence, screen repositories, and build the catalog database. |
| [Deployment](web/deploy/README.md) | Run the application behind Nginx with HTTPS and sign-in. |

Start with the [offline catalog example](web/examples/catalog/README.md) to build a small database and launch the application without API credentials.
